# portfolio-v3

Static personal site built with Astro, Tailwind CSS v4 and shadcn/ui tokens.

## Setup

Requires Node 22.23.4 or newer (Astro 7) and pnpm.

```sh
pnpm install
```

## Commands

| Command        | Action                                    |
| -------------- | ----------------------------------------- |
| `pnpm dev`     | Start the dev server (http://localhost:4321) |
| `pnpm build`   | Build the static site to `./dist`         |
| `pnpm preview` | Serve the built site locally              |
| `pnpm check`   | Type-check with `astro check`             |
